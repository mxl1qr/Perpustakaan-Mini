### Answer

To replicate this sidebar in your Laravel project, you should use **Tailwind CSS** (which this site uses) alongside Laravel's **Blade components**. 

The sidebar uses a `fixed` position with a width of `1/6` on large screens and is hidden on mobile.

### 1. The Blade Component
Create a file at `resources/views/components/sidebar.blade.php`:

### 2. The Link Component (Optional but Recommended)
Create `resources/views/components/sidebar-link.blade.php` to handle the "Active" state styles automatically:


`````html
@props(['active'])

@php
$classes = ($active ?? false)
            ? 'flex items-center space-x-3 p-2 pl-6 border-l-4 border-blue-600 bg-gray-50 text-blue-600 font-semibold transition'
            : 'flex items-center space-x-3 p-2 pl-6 border-l-4 border-transparent text-gray-500 hover:bg-gray-50 hover:text-blue-500 transition';
@endphp

<a {{ $attributes->merge(['class' => $classes]) }}>
    {{ $slot }}
</a>
`````


### 3. Usage in Layout
In your `layouts/app.blade.php`, make sure your main content is offset to the right so it doesn't hide behind the fixed sidebar:


`````html
<div class="flex min-h-screen">
    <!-- Sidebar -->
    <x-sidebar />

    <!-- Main Content -->
    <!-- The margin-left (ml-[16.66%]) matches the 1/6 width of the sidebar -->
    <main class="w-full lg:ml-[16.66%] p-8">
        {{ $slot }}
    </main>
</div>
`````


### Key Technical Details:
*   **`fixed left-0 top-0 h-screen`**: This keeps the sidebar pinned to the left side regardless of scrolling.
*   **`overflow-y-auto`**: Ensures that if you have many menu items, the sidebar itself is scrollable.
*   **`border-l-4`**: The original site uses a thick left border to indicate which page is currently active.
*   **`lg:block` vs `hidden`**: This ensures the sidebar only appears on desktop screens (>= 1024px). For mobile, you would typically use a separate hamburger menu or a bottom navigation bar.
